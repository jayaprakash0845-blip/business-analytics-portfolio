# Jayaprakash M. — Business Analytics Portfolio

## Files
- index.html
- style.css
- script.js

## Setup
1. Put all three files in the same folder.
2. Open index.html in a browser.
3. Add your own `resume.pdf` in the same folder.
4. Replace the GitHub, LinkedIn and email placeholders in index.html/script.js.
5. Replace certification placeholders with your real certificates.

## Publish
Upload the three files plus `resume.pdf` to any static hosting provider.

No build step is required.
